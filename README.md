# New Super Polymers — website

A 15-page static site for New Super Polymers India Pvt Ltd. Plain HTML, CSS and vanilla
JavaScript — no framework, no build step required to deploy, no runtime dependencies.

## Run it locally

```bash
python3 -m http.server 4177
```

Then open <http://localhost:4177>.

## Deploy it

Upload the whole folder to any static host or web server. Nothing else is needed.
`build.py` and this README are development files and do not have to be uploaded.

Set the document root to the folder containing `index.html` and point `404.html` at your
server's not-found handler.


## Editing content

Every page is generated by `build.py`, so edit there and re-run:

```bash
python3 build.py
```

Content lives in named blocks near the top of the file: `PRODUCTS`, `INDUSTRIES`,
`BASE_SPEC`, `COLOURS`, `STAGES`, and the contact constants (`TEL1`, `MAILSA`, `ADDR`…).
Editing the generated `.html` files directly also works, but a rebuild will overwrite it.

## Before this goes live — four things

### 1. Confirm the flagged specifications

`build.py` sets `DRAFT = True`. While it is true, specification values that were **not**
published on the existing site carry a small orange `verify` flag in the spec tables:

| Specification | Value used | Source |
|---|---|---|
| Lay-flat width | 25 – 1000 mm (1" – 40") | industry default — **confirm** |
| Roll length | 50 – 500 m, made to order | industry default — **confirm** |
| Core | 76 mm (3") ID paper core | industry default — **confirm** |
| Gauge tolerance | ±5% on nominal | industry default — **confirm** |
| Width tolerance | ±2 mm | industry default — **confirm** |
| Terms | EXW Vasai · FOB Nhava Sheva · CIF | recommendation — **confirm** |

Everything else (gauge 0.05–0.40 mm, 50–400 micron, tubing roll packaging, plain pattern,
ISO 9001:2015, 45–60 day lead time) comes from the existing site or from the client.

Correct the values in `BASE_SPEC`, set `DRAFT = False`, and re-run `build.py`. The flags
disappear.

### 2. Wire up the RFQ form

`contact.html` has a complete request-for-quotation form. It currently has no `action`:
`site.js` intercepts the submit and shows a confirmation so the page can be demonstrated.

To make it live, give the `<form data-rfq>` element an `action` (and `method="POST"`) —
Formspree, Netlify Forms, or your own handler — and remove the `data-rfq` attribute so
`site.js` stops intercepting it. The form is in the `build_contact()` function.

Route submissions to `sales@newsuperpolymers.com`.

### 3. Compliance claims

The quality page deliberately claims **only** ISO 9001:2015, which is documented. Food
contact, medical, RoHS, REACH and phthalate-free are framed as "quoted against the standard
you need" rather than asserted. Do not upgrade that wording to a claim of certification
without holding the certificate — buyers in the US and the Gulf verify these.

### 4. Photography

Every image on the site is an original SVG illustration drawn for this project. They are
technically accurate and carry no licensing risk, but real photographs of the Vasai plant
would be stronger still. Highest-value shots, in order:

1. A line running — the bubble, lit, with the collapsing frame behind it
2. The winder with a finished roll coming off
3. Roll racks / finished goods stacked by colour
4. The QC bench with a thickness gauge on a sample
5. The team on the floor
6. Building exterior

Drop them into `assets/img/` and swap the `<img src>` in the relevant `build.py` block.
The illustrations can stay alongside — a diagram next to a photograph reads better than
either alone.

Also outstanding: a photograph of the director for `about.html` (currently a marked
placeholder), and a vector version of the logo if one exists.

## Design system

Defined entirely in CSS custom properties at the top of `assets/css/site.css`.

**"Petrol Glass".** One continuous deep-petrol ground — the colour of clear PVC seen in
bulk — with translucent glass panels floating on it. No section ever flips to white:
variation comes from elevation and hue drift, never from inverting the page.

- **Ground** `#050F15` → `#0C1F28`, hue-biased petrol, never neutral black
- **Glass** `rgba(214,238,242,.045)` panels, `.10` edges, 1px inset specular top-line
- **Accent** champagne gold `#E8C08A` with molten copper `#D9743C` — one warm family
  against the cool ground; gold for elegance, copper for the melt
- **Rubik** for statements and structure (600 for display, tight negative tracking;
  300 italic for pull quotes), **IBM Plex Mono** for technical data
- Fixed ambient light behind the whole page (`body::before`) plus a fine grain layer
  (`body::after`) that prevents banding in the large gradients
- Fluid type scale — every size is a `clamp()`, so nothing needs breakpoint overrides
- Breakpoints at 1180px (nav collapses), 960px, 900px, 760px, 700px, 620px, 560px, 400px

The section classes `.dark`, `.dark-2` and `.paper-2` are retained from the earlier build
but now mean *elevation tiers within the same petrol world*, not light/dark inversions.
Legacy token names (`--ink`, `--paper`, `--fg-inv`…) are kept as aliases so inline styles
authored against the previous palette still resolve correctly.

**Logo.** A glass tile carrying an `N` monogram in a gold gradient over faint wound-roll
arcs, with a molten line beneath standing for the film web. The header lockup is large at
rest (72px mark, 30px wordmark) and contracts on scroll (44px / 19px), so the brand gets
real presence without permanently eating the viewport. `LOGO(sfx)` in `build.py` takes a
suffix so its gradient ids stay unique per instance.

## Accessibility & SEO

- Skip link, `aria-current` on the active nav item, labelled form fields, focus-visible rings
- `prefers-reduced-motion` honoured throughout
- Reveal animations are guarded behind a `js` class, so all content renders with JS disabled
- Per-page `<title>`, meta description, canonical and Open Graph tags
- JSON-LD: `Organization` on the home page, `Product` on each product page
- `sitemap.xml` and `robots.txt` generated by the build (the current site has neither)
